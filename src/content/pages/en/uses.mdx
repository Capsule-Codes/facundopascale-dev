This is the page where I list — in too much detail — the tools I use every single day. If you're a dev, you probably enjoy these pages as much as I do.

## Editor and terminal

- **LazyVim** as my primary editor (preconfigured Neovim with modern sensibilities)
- **Zellij** and **Tmux** for pane and session management
- **Ghostty** as terminal emulator
- **JetBrains Mono** as code font
- **Vesper** or **Tokyo Night** as color scheme (depends on the day)

## Main languages and frameworks

- **TypeScript** (strict, always)
- **React 19** with React Compiler — no more manual `useMemo`/`useCallback`
- **React Native + Expo** for mobile
- **Astro 6** for content sites (like this one)
- **Next.js 16** for fullstack apps
- **Tauri v2** for desktop

## Libraries I reach for on every project

- **Tailwind CSS 4** — styling
- **Zod** — validation and schemas
- **Zustand** — state management
- **TanStack Query** — data fetching
- **Drizzle ORM** — database
- **Resend** — transactional email

## Hardware

- MacBook Pro M3 Max
- Keyboard: Keychron Q1 with Gateron Brown switches
- Monitor: Apple Studio Display
- Webcam: Logitech Brio
- Microphone: Shure SM7B with Cloudlifter

## Services

- **Vercel** for hosting and CI/CD
- **Supabase** as default BaaS
- **GitHub** for repos and Actions
- **Linear** for tracking
- **1Password** for secrets
